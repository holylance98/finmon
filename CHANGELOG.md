# Changelog
Формат — Keep a Changelog, версионирование — SemVer.

## [1.0.0] - 2026-10-05
### Added
- Модель договора и платежа на `Decimal` (без ошибок округления).
- Помесячный график платежей с учётом скидки, распределение поступлений по FIFO.
- Расчёт просрочки, договорных пеней (1/300 ключевой ставки ЦБ РФ) и возрастных корзин долга.
- Объяснимый скоринг платёжной дисциплины (4 класса риска) с решением по рассрочке.
- Сводка портфеля, претензионная очередь, расчёт упущенной выгоды и безубыточного платежа.
- Маскирование ПДн, PBKDF2-хэширование паролей, журнал операций с hash-цепочкой.
- CLI (`report`, `economics`), 24 юнит-теста, CI на Python 3.10-3.12.

### Planned
- REST API + RBAC, PostgreSQL, интеграции с 1С и LMS, ML-прогноз оттока платежей.

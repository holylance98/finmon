# FinMon — модуль финансового мониторинга договоров образовательных услуг

Учебный реализованный прототип в рамках производственной практики
(Университет «Синергия», направление — разработка ПО для финтех-проектов).

Считает график платежей по договорам, просроченную задолженность и договорные пени,
присваивает рейтинг платёжной дисциплины, формирует претензионную очередь и
обезличенный отчёт; ведёт защищённый журнал операций.

## Быстрый старт (только стандартная библиотека, зависимостей нет)

```bash
git clone https://github.com/<USERNAME>/finmon.git
cd finmon
python -m unittest discover -s tests -v      # 24 теста
python -m src.cli report --today 2026-06-01 --out out/report.csv
python -m src.cli economics --plan 259200 --installments 10 --annual-rate 21
```

## Структура

```
finmon/
├── src/
│   ├── models.py       # доменные модели, Decimal для денег
│   ├── billing.py      # график, FIFO-распределение, просрочка, пени, aging
│   ├── scoring.py      # рейтинг платёжной дисциплины 0-100
│   ├── analytics.py    # сводка портфеля, NPV/IRR, претензионная очередь
│   ├── security.py     # маскирование ПДн, PBKDF2, аудит с hash-цепочкой
│   └── cli.py          # командный интерфейс
├── tests/              # 24 юнит-тестаа (unittest)
├── data/               # синтетические договоры и платежи
├── docs/requirements.md    # функциональные и нефункциональные требования, регуляторика, приёмка
├── docs/architecture.md    # схема, стек, план тестирования
└── .github/workflows/ci.yml
```

## Что реализовано
* помесячный график с учётом скидки, сумма платежей = сумма к оплате;
* FIFO-распределение поступлений, расчёт долга, пени (1/300 ключевой ставки ЦБ РФ за день),
  разбивка по корзинам 1-30 / 31-60 / 61-90 / >90 дней;
* объяснимый скоринг (4 класса риска) с решением по рассрочке;
* IRR графика рассрочки — цена предоставленной отсрочки;
* обезличивание ФИО (`152-ФЗ`), PBKDF2 для паролей, неизменяемый журнал с проверкой целостности.
